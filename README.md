## About

DBeaver is a free, open-source universal database client for Windows, macOS, and Linux supporting over 100 databases including PostgreSQL, MySQL, SQLite, SQL Server, Oracle, and MongoDB. Features include a visual query builder, ER diagram viewer, data editor, import/export, and SQL completion. DBeaver Community Edition is the go-to free alternative to commercial database clients for developers and DBAs.

## Common Problems & Limitations

- **Performance with Large Data** — Very large tables can be slow to browse without proper pagination
- **Commercial Pro Features** — Advanced data profiling and collaboration features require paid edition
- **Memory Usage** — Java-based application with moderate memory overhead
- **Connection Complexity** — Some database drivers require manual JDBC configuration
